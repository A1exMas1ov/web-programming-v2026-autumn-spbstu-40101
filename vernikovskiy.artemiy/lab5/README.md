# Лабораторная работа 5

## Задание

Вариант 27.

```
Задача 5. Реализовать слайдер книг в книжном интернет-магазине
Создать слайдер на главной странице магазина состоящий из карточки
книги.
Карточка должна содержать обложку книги, название, рейтинг, описание и
цену.
Функционал слайдера:
- кнопки далее и назад;
- подпись текста к каждому слайду;
- вывод номера и максимального количества (1/3,2/3,/3/3);
- пагинация (при клике - переключается на нужный слайд)
```

## Реализация

Захардкодил пять книг. Пользователь может переходить между книгами через кнопки
"вправо", "влево" и через слайдер. Список зациклен.

Компоненты:

- `App` - главный компонент, тут всё ** `currentSlide` (состояние) - индекс
  текущей книги
- `BookCard` - компонент, отображающий информацию о книге ** `id`, `title`,
  `author`, `rating`, `description`, `price`, `coverColor`, `coverText` -
  состояния компонента. coverColor и coverText - обход нужды в картинке для
  обложки.

## Запуск

Выполните `npm install`, затем `npm run dev` в каталоге лабораторной.
