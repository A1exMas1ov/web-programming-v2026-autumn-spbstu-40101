# Лабораторная работа 4

## Задание

Вариант 25. Задача 4. 4.1. Создать класс product с полями: • id — уникальный
идентификатор (число) • name — название товара (строка) • categories — массив
категорий (строки) • price — цена (число) Реализовать методы: •
addCategory(category) — добавить категорию • removeCategory(category) — удалить
категорию • геттер categoryCount — количество категорий 4.2. Дан массив товаров:
• Реализовать функцию, которая группирует товары по категориям • Реализовать
функцию, возвращающую уникальные категории 76 • Реализовать функцию, которая
группирует товары по диапазонам цен • Реализовать функцию, которая возвращает
товары, входящие в заданную категорию • Реализовать функцию, которая возвращает
товары с ценой выше заданной 4.3. Реализовать пользовательский интерфейс: •
Карточки товаров: название, цена, список категорий • Кнопки: "Добавить
категорию", “Удалить категорию”, “Добавить товар”, "Удалить товар" • Форма
создания товара (ID, название, цена). Форма добавления категории. • При любых
изменениях автоматически обновлять пользовательский интерфейс • Все операции
добавления/удаления выполнять асинхронно через Promise

- setTimeout() • Использовать local storage для сохранения текущего списка
  студентов при закрытии вкладки

## Реализация

Модель (model.js). Класс Product с полями id, name, categories, price, методами
addCategory, removeCategory и геттером categoryCount. Функции работы с массивом
товаров: groupByCategory (группировка по категориям), getUniqueCategories
(уникальные категории), groupByPriceRange (группировка по диапазонам цен),
getProductsByCategory (товары категории), getProductsAbovePrice (товары дороже
заданной цены).

Интерфейс (main.js). Товары выводятся карточками (название, цена, категории).
Форма создаёт товар, в карточке есть кнопки добавления, удаления категории и
удаления товара. Все изменения выполняются через runAsync (Promise +
setTimeout): после действия данные сохраняются в localStorage, а список
перерисовывается. При открытии страницы список загружается из localStorage.

## Запуск

Откройте `index.html` в браузере.
