# Лабораторная работа 4

## Задание

Вариант 2.

Реализовать класс студента с идентификатором, именем и оценками, функции работы
с коллекцией студентов и пользовательский интерфейс для добавления и удаления
студентов и оценок.

Изменения должны выполняться асинхронно, а данные сохраняться в localStorage.

## Реализация

В `model.js` реализован класс `Student` и функции работы с коллекцией студентов.

В `main.js` реализованы работа с DOM, асинхронное добавление и удаление данных и
сохранение списка студентов в localStorage.

## Запуск

Запустить локальный сервер:

```bash
python3 -m http.server 8000
```
