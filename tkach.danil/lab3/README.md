# Лабораторная работа 3

## Задание

Вариант 2.

Реализовать функцию `rotateArray(arr, steps)`, выполняющую циклический сдвиг
массива вправо на `steps` элементов.

## Реализация

Функция `rotateArray` экспортируется как именованный ES module export.

Количество шагов нормализуется с помощью остатка от деления на длину массива.
Массив разделяется на две части методом `slice`, после чего части объединяются в
новом порядке с помощью spread-синтаксиса.

Исходный массив не изменяется.

## Запуск

Импортировать именованный export `rotateArray` из файла `solution.js` как ES
module.
